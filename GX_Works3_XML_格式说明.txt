一、XML格式要求
================================================================================

1. 文件头部
   - 编码: utf-8 (不是utf-16)
   - 命名空间: www.iec.ch/public/TC65SC65BWG7TF10
   - 标准: IEC 61131-10 (不是PLCopen TC6)

2. 基本结构
   <?xml version="1.0" encoding="utf-8"?>
   <Project xmlns="www.iec.ch/public/TC65SC65BWG7TF10" 
            xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" 
            schemaVersion="1.000">

3. 元素大小写
   - 使用 <Project> 不是 <project>
   - 使用 <Program> 不是 <program>
   - 所有主要元素首字母大写

二、XML结构层次
================================================================================

Project
├── FileHeader (公司信息)
├── ContentHeader (项目信息)
├── Types
│   └── GlobalNamespace
│       ├── AddData (必需的FbFiles信息)
│       ├── FunctionBlock (功能块，可选)
│       └── Program (主程序)
└── Instances
    └── Configuration
        ├── Resource (程序实例)
        └── GlobalVars (全局变量，可多组)

三、关键元素模板
================================================================================

1. 文件头部
<FileHeader companyName="MITSUBISHI ELECTRIC CORPORATION" 
            companyURL="http://www.mitsubishielectric.com" 
            productName="GX Works3" 
            productVersion="ver.1.0" />

2. 程序定义
<Program name="程序名称">
  <AddData>
    <Data name="http://www.mitsubishielectric.com/xml/PouProperties" handleUnknown="implementation">
      <PouProperties title="程序名称" version="ver.1.000" helpFilePath="" supportVersion="1.000W" />
    </Data>
  </AddData>
  
  <Vars constant="false" accessSpecifier="private">
    <Variable name="变量名"><Type><TypeName>BOOL</TypeName></Type></Variable>
  </Vars>
  
  <MainBody>
    <BodyContent xsi:type="ST">
      <ST>(* ST代码 *)</ST>
    </BodyContent>
  </MainBody>
</Program>

3. 全局变量
<GlobalVars constant="false">
  <AddData>
    <Data name="http://www.mitsubishielectric.com/xml/GlobalVarsProperties" handleUnknown="implementation">
      <GlobalVarsProperties name="组名" title="组名" version="ver.1.000" helpFilePath="" supportVersion="1.000W" />
    </Data>
  </AddData>
  
  <Variable name="变量名">
    <Type><TypeName>BOOL</TypeName></Type>
    <Address address="X0" />
  </Variable>
</GlobalVars>

重要发现：GX Works3中文注释的正确处理方式

经过测试确认：
1. XML导入时使用简洁格式（不包含variableComments）
2. 导入成功后在GX Works3中手动添加中文注释
3. 导出时可获得包含中文注释的完整XML和CSV文件

正确的导入XML格式（简洁版）：
<Variable name="变量名">
  <Type><TypeName>BOOL</TypeName></Type>
  <Address address="X0" />
</Variable>

导出的XML格式（包含注释）：
<variable name="变量名" address="LV:0.0">
  <type><BOOL /></type>
  <addData>
    <data name="http://www.mitsubishielectric.com/xml/variableComments" handleUnknown="implementation">
      <variableComments>
        <comment number="1">
          <html xml:space="preserve" xmlns="http://www.w3.org/1999/xhtml">中文注释内容</html>
        </comment>
      </variableComments>
    </data>
  </addData>
</variable>

推荐工作流程：
1. 使用简洁XML格式导入程序
2. 在GX Works3标签编辑器中添加中文注释
3. 导出CSV或XML文件保存完整版本

补充：CSV标签导入格式规范（已验证可导入）
================================================================================

重要说明：GX Works3“从CSV文件导入”对格式非常敏感。以下规范以从GX Works3导出并验证可正常导入的
Motor_Control_test1.csv 为标准模板。

1. 编码
   - 必须为 UTF-16（带BOM）

2. 分隔符
   - 必须使用 TAB（制表符）分隔列
   - 不能使用逗号分隔

3. 引号
   - 每个字段必须使用英文双引号 " 包裹

4. 全局/局部必须分开导入
   - 全局标签CSV：第1行必须为 "(工程未设置)"
   - 局部标签CSV：第1行必须为 "(ProgramName)"，例如 "(Motor_Control)"
   - 不要把全局与局部标签混在同一个CSV文件里导入

5. 标签名必须精确匹配工程内名称
   - 例如工程内全局变量为 gStart_Button，则CSV的“标签名”列也必须为 gStart_Button
   - 如果名称不一致，导入会失败或导入后无法对应到正确标签

四、数据类型和地址
================================================================================

数据类型:
- BOOL: 布尔型
- INT: 整数型  
- TIME: 时间型
- TON: 定时器

地址映射:
- 输入: X0, X1, X2...
- 输出: Y0, Y1, Y2...
- 内部: M0, M1, M2...
- 寄存器: R100, R102, R104...

初始值设定:
<InitialValue><SimpleValue value="TRUE" /></InitialValue>

五、常见错误
================================================================================

❌ 错误做法:
- encoding="UTF-16"
- xmlns="http://www.plcopen.org/xml/tc6_0201"
- <project>, <program>
- 缺少AddData元素

✅ 正确做法:
- encoding="utf-8"
- xmlns="www.iec.ch/public/TC65SC65BWG7TF10"
- <Project>, <Program>
- 包含所有必需的AddData

六、导入步骤
================================================================================

1. 打开GX Works3
2. 文件 → 导入
3. 选择 "IEC 61131-10"
4. 选择XML文件
5. 确认导入

七、最佳实践
================================================================================

1. 使用Windsurf生成XML (最可靠)
2. 按功能分组全局变量
3. 合理规划I/O地址
4. 添加详细的ST代码注释
5. 维护版本信息
